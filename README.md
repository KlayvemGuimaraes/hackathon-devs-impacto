## 🎯 Visão Geral

O **Bem-Estar Hub** é uma plataforma completa de bem-estar que utiliza **Inteligência Artificial local** para promover saúde preventiva e reduzir a sobrecarga do sistema público de saúde. 

Inspirado no design sofisticado da **Vercel** e **Linear**, o projeto combina:

- 🧠 **IA Preditiva** - Detecta sinais precoces de ansiedade, fadiga e estresse
- 🍎 **Nutrição Inteligente** - Planos alimentares personalizados
- 💪 **Treinos Adaptativos** - Exercícios para todos os níveis
- 🧘 **Saúde Mental** - Chat empático com IA, meditação e mindfulness

## 🚀 Instalação e Execução

### Pré-requisitos

- Node.js >= 18
- npm ou yarn

### Passos

1. **Clone o repositório**

## 🧠 Como Funciona a IA

### Análise de Estado Mental

O core da IA (`src/core/core-ai.js`) implementa:

1. **Detecção de Keywords** - Identifica palavras-chave relacionadas a emoções
2. **Classificação de Humor** - Categoriza em: ansioso, triste, cansado, animado, confuso
3. **Sugestões Contextuais** - Retorna ações personalizadas:
   - Atividades (caminhada, meditação, etc.)
   - Nutrição (alimentos e bebidas recomendadas)
   - Exercícios (tipo e intensidade)
4. **Insights Preditivos** - Analisa padrões de comportamento ao longo do tempo

### Exemplo de Resposta da IA

```json
{
  "success": true,
  "mood": "ansioso",
  "level": "moderado",
  "suggestion": "Tente uma caminhada leve de 15 minutos e pratique respiração profunda (4-7-8).",
  "activities": ["Caminhada leve", "Respiração 4-7-8", "Meditação guiada"],
  "nutrition": "Chá de camomila ou água com limão pode ajudar a acalmar.",
  "exercise": "Yoga ou alongamento suave por 10-15 minutos.",
  "timestamp": "2025-10-26T10:30:00Z",
  "confidence": "alta"
}
```

## 🎨 Design Principles

### Inspiração Vercel

- **Clean & Minimal** - Foco no conteúdo, sem ruído visual
- **Typography-First** - Hierarquia clara com Poppins e Inter
- **Subtle Animations** - Transições suaves que não distraem
- **Dark Mode Native** - Modo escuro de primeira classe
- **Gradient Accents** - Uso estratégico de gradientes

### Cores

```css
/* Azul (Primary) */
--primary-500: #1890ff;
--primary-600: #096dd9;

/* Verde-Limão (Accent) */
--lime-500: #a0d911;
--lime-600: #7cb305;

/* Neutros */
--gray-50: #fafafa;
--gray-900: #0a0a0a;
```
